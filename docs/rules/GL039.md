# GL039 — Security-check command silenced with `|| true`

**Severity:** `warn`  
**OWASP:** [CICD-SEC-1 – Insufficient Flow Control Mechanisms](https://owasp.org/www-project-top-10-ci-cd-security-risks/CICD-SEC-01-Insufficient-Flow-Control-Mechanisms)

## What glsec checks

glsec flags script lines where a known security audit tool is followed by `|| true`, `|| exit 0` or `|| :`. These constructs force exit code 0 regardless of whether vulnerabilities were found, making the job always green and silently discarding the audit result. The pipeline continues as if no findings exist.

Detected tools:

| Kind | Tools |
|------|-------|
| Dependencies and images | `npm audit`, `pnpm audit`, `yarn audit`, `composer audit`, `trivy`, `grype`, `snyk`, `osv-scanner`, `retire`, `safety check/scan`, `anchore-cli`, `inspector check`, `syft`, `govulncheck`, `pip-audit`, `dependency-check`, `cargo audit`, `cargo deny`, `bundle-audit` |
| Secrets | `gitleaks`, `trufflehog`, `ggshield`, `detect-secrets` |
| SAST | `semgrep`, `gosec`, `bandit`, `brakeman` |
| Infrastructure as code | `checkov`, `tfsec`, `kics`, `terrascan`, `kubescape` |

The tools in the last three rows and `govulncheck` through `bundle-audit` count only as the command itself: at the start of a command, through a runner such as `npx`, `pipx run`, `poetry run`, `uv run`, `bundle exec`, `python -m` or `go run`, or behind a path. Installing one (`pip install pip-audit || true`, `go install …/gosec@latest || true`) is not flagged.

## Trigger example

```yaml
security:
  script:
    - npm audit --audit-level=high || true    # CVEs silently ignored
    - trivy image myapp:latest || true        # vulnerabilities discarded
    - 'gitleaks detect --source . || :'       # leaked secrets ignored; quoted, since ": " would start a YAML mapping
```

## Safe alternatives

**Remove the silencing and fix the findings:**
```yaml
security:
  script:
    - npm audit --audit-level=high
```

**If the pipeline must stay green while the backlog is being cleared, use job-level `allow_failure:` — this keeps the signal visible in the UI:**
```yaml
security:
  allow_failure: true
  script:
    - npm audit --audit-level=high
```
